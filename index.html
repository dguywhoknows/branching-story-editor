What it does

Everything in one place

Layered graph layout

Layered graph layout (BFS depth) with curved edges, pan/zoom, and '+' stubs for unwritten choices

AI branch writing

AI branch writing with path-aware context; nudges toward endings as paths deepen

Passage editor

Title, text, endings, choices wired to new or existing passages (merge branches)

AI suggest-choices

AI suggest-choices and rewrite-in-tone (more vivid, darker, funnier, shorter, more dialogue)

AI continuity check along the

AI continuity check along the path to any passage

Story stats

Passages, endings, open threads, longest path, unreachable nodes

Gamebook play mode

Gamebook play mode with back navigation; Twee 3 (Twine 2/Harlowe) and JSON export/import

Story variables

Choices can be shown only when a condition holds (trust >= 2 && hasKey) and can change variables when taken (trust += 1; hasKey = true); passages can show {variables} and {if …}…{/if} text. Expressions use a small tokenizer and recursive-descent parser, never eval

Analysis page

Explores every reachable (passage, variables) state to report which endings can actually be reached and how often, unreachable passages, dead ends, choices whose conditions can never be met, unwritten choices and invalid logic

Questions

Good to know

Is it free?

Yes. Every feature is free.

Where is my data stored?

What you create stays in this browser on this device. You can export a backup or delete everything from Settings.

Do I need an API key?

Not to try it: the app runs in demo mode with sample AI output. For live AI, connect a free Groq or OpenRouter key in Settings.

What can I type into the AI box?

Anything you would ask a helpful colleague who knows the app, such as: "Start a sci-fi story about a lighthouse on Mars". It plans the steps, runs the app's own functions and tells you what it did. The Instructions tab saves preferences every AI feature follows.

Can I see the code?

Yes. It is open source under the MIT license on GitHub, with a public test suite.
